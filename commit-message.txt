## Trading Desk Enhancements (`trading/page.tsx`)

### 1. Functional Create Listing Form
**Before:** Form inputs were static placeholders with no state or handlers.
Clicking "Create Listing" did nothing.

**After:** Fully wired form that creates listings and adds them to state.

- **Credit selection** — Radio buttons bound to `selectedCreditId` state;
  selected credit highlights with blue border (`bg-blue-500/10`)
- **Listing type toggle** — `fixed | auction | negotiable` buttons with
  active state styling; defaults to `fixed`
- **Dual-currency pricing** — USD and NEAR inputs with auto-conversion
  using `NEAR_USD_RATE` (1 NEAR ≈ $4.25 USD); changing one updates the other
- **Quantity input** — Bound to state with `min="1"` and `step="1"`
- **Duration selector** — Controlled `<select>` for 7/14/30/60 days
- **Form validation** — Submit disabled until credit selected, price > 0,
  and quantity > 0; visual disabled state (`bg-white/10 text-white/40
  cursor-not-allowed`); validation hint text shown when invalid
- **Create handler** — `handleCreateListing()` builds a `MarketplaceListing`
  object from form state, prepends to listings array, resets form, and
  switches to "My Listings" tab

### 2. Dynamic Fee Estimate Panel
**Before:** Static `$0.00` values.

**After:** Real-time calculation based on form inputs.

```typescript
const totalValue = usdPrice * qty
const platformFee = totalValue * 0.02     // 2% platform fee
const nearGasFee = 0.01                   // Estimated NEAR gas
const netProceeds = totalValue - platformFee
```

- Listing Value, Platform Fee, NEAR Gas Fee, and Net Proceeds update
  live as user types price/quantity
- Net Proceeds displayed in green (`text-green-400`)

### 3. Required Field Indicators
- Added red asterisk (`*`) to required fields: "Select Credits to Sell",
  "Price per Credit", "Quantity to List"
- NEAR input shows Ⓝ symbol on right side with proper padding (`pr-8`)
- Exchange rate hint below price inputs

## Technical Details

### Create Listing Flow
```
1. User selects credit from holdings (radio button)
2. User picks listing type (fixed/auction/negotiable)
3. User enters price in USD or NEAR (auto-converts)
4. User sets quantity and duration
5. Form validates: credit + price + quantity required
6. User clicks "Create Listing"
7. handleCreateListing() builds MarketplaceListing object
8. New listing prepended to myListings via setMyListings()
9. Form resets to defaults
10. Tab switches to "My Listings" showing new listing
```

### USD ↔ NEAR Conversion
```typescript
// USD → NEAR
const handleUsdChange = (value: string) => {
  setPriceUsd(value)
  setPriceNear((parseFloat(value) / NEAR_USD_RATE).toFixed(2))
}

// NEAR → USD
const handleNearChange = (value: string) => {
  setPriceNear(value)
  setPriceUsd((parseFloat(value) * NEAR_USD_RATE).toFixed(2))
}
```
