fix(marketplace): improve CreditCard UX and fix filter functionality

This commit addresses several UX improvements and bug fixes in the Carbon
Credit Marketplace dashboard.

**Bug Fixes**

1. **Fixed Filters Not Working**
   - Added explicit `credits` state subscription to MarketplaceFilters and 
     marketplace page components
   - Wrapped `filteredCredits()` in `useMemo` with proper dependencies for
     reactivity when filters change
   - Fixed checkbox toggle - changed `<label>` to `<button>` with `onClick`
     handler (checkboxes were not responding to clicks)

2. **Fixed SDG Tooltip Visibility**
   - Implemented React Portal for SDG tooltips to escape card's overflow:hidden
   - Tooltips now render to document.body and appear above cards properly
   - Shows full SDG name on hover (e.g., "SDG 13: Climate Action")

**UX Improvements**

1. **Consistent Card Heights**
   - Added `min-h-14` (56px) to project name for 2-line title space
   - Added `min-h-10` (40px) to methodology name with `line-clamp-2`
   - All credit cards now maintain uniform height regardless of text length

2. **Reorganized CreditCard Layout**
   - Moved "Jobs Created" section before SDGs for better visual hierarchy
   - Split bottom section 50/50: Tonnage (left) | Price (right)
   - Tonnage now displays with leaf icon, quantity, and "tonnes CO₂" label
   - Price section aligned right with USD and NEAR values

3. **Added Solid Mode to GlassCard**
   - New `solid` prop for overlay/modal panels
   - Uses opaque `bg-gray-900` instead of transparent glass effect
   - Applied to mobile filters panel for better visibility on overlay
   - Updated GlassCardProps interface with JSDoc documentation

**Technical Details**

SDG Tooltip Implementation:
```typescript
function SDGBadge({ sdg }: { sdg: number }) {
  const [isHovered, setIsHovered] = useState(false)
  const [position, setPosition] = useState<{ top: number; left: number } | null>(null)
  const badgeRef = useRef<HTMLSpanElement>(null)

  // Calculate position on mouse enter (once, not continuously)
  const handleMouseEnter = () => {
    if (badgeRef.current) {
      const rect = badgeRef.current.getBoundingClientRect()
      setPosition({ top: rect.top - 8, left: rect.left + rect.width / 2 })
      setIsHovered(true)
    }
  }

  return (
    <>
      <span ref={badgeRef} onMouseEnter={handleMouseEnter} ... />
      {isHovered && position && createPortal(<Tooltip />, document.body)}
    </>
  )
}
```
