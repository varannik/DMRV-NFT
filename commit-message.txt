feat(dashboard): major UI/UX overhaul with floating sidebar, detail modal, and filter fixes

This commit introduces significant UI improvements across the dashboard, focusing on
professional design patterns, improved interactions, and bug fixes.

## New Features

### 1. CreditDetailModal - Project Details View
- **New component** for viewing full project details when clicking credit cards
- Displays header image with registry badge and verification status
- Shows project location with map coordinates and "Open in Maps" link
- Two-column layout: Location/Map | Verification & Standards
- Co-benefits displayed as colorful badges (Biodiversity, Community, Indigenous Rights, Jobs)
- Full SDG list with color-coded badges showing goal names
- Certifications section when available
- Purchase section with available credits, price, and "Buy Credits" button
- Watchlist heart button integration
- Click outside or X button to close

### 2. Floating Sidebar Design
- **Sidebar now floats** with 16px margins from top, bottom, and left edges
- Rounded corners (`rounded-2xl`) for modern card appearance  
- Deep shadow (`shadow-2xl shadow-black/40`) for depth
- Mobile sidebar also adopts floating card style when expanded
- Right sidebar (StepsTracker) matches the floating design

### 3. Professional Sidebar Toggle
- **Logo click toggles sidebar** expansion (previously navigated)
- Animated logo with wobble on hover and shine sweep effect
- Expand indicator (chevron) appears on logo hover when collapsed
- Toggle button shows only when expanded, with gradient background
- Smooth width transition animations

### 4. Improved Modal Design
- **BuyModal** redesigned to fit on screen without scrolling
- Compact layout with reduced padding and margins
- Click outside modal to close (backdrop click handler)
- Uses `solid` prop on GlassCard for opaque background
- Professional three-step flow: Details → Confirm → Success

## Bug Fixes

### 1. Fixed Filters Not Working
- Added explicit `credits` state subscription in MarketplaceFilters
- Wrapped `filteredCredits()` in `useMemo` with proper dependencies
- Fixed CheckboxItem: changed `<label>` to `<button>` with `onClick` handler

### 2. Fixed SDG Tooltip Visibility
- Implemented React Portal for tooltips to escape `overflow:hidden`
- Tooltips render to `document.body` and appear above cards
- Position calculated once on mouse enter (no jittery movement)
- Shows "SDG {number}: {Full Name}" on hover

### 3. Fixed Card Height Inconsistency
- Added `min-h-14` (56px) to project name for 2-line title space
- Added `min-h-10` (40px) to methodology name with `line-clamp-2`
- All credit cards now maintain uniform height

### 4. Fixed Page Title Alignment
- Page titles now align with top of sidebar content
- Desktop: 32px top padding (16px sidebar margin + 16px internal padding)
- Mobile: 80px top padding for hamburger menu
- Consistent margin calculations accounting for floating sidebar

## Technical Details

### Sidebar Margin Calculation
```typescript
// Content margins account for floating sidebar
const leftMargin = isExpanded ? 312 : 112  // 16px + width + 16px gap
const rightMargin = showRightSidebar ? 336 : 0
return { marginLeft, marginRight, paddingTop: 32 }  // 32px aligns with sidebar content
```

### Portal-Based Tooltips
```typescript
function SDGBadge({ sdg }: { sdg: number }) {
  const handleMouseEnter = () => {
    const rect = badgeRef.current.getBoundingClientRect()
    setPosition({ top: rect.top - 8, left: rect.left + rect.width / 2 })
    setIsHovered(true)
  }
  
  return (
    <>
      <span ref={badgeRef} onMouseEnter={handleMouseEnter} ... />
      {isHovered && position && createPortal(<Tooltip />, document.body)}
    </>
  )
}
```

### Click Outside to Close Pattern
```tsx
{/* Backdrop - click closes modal */}
<motion.div onClick={onClose} className="fixed inset-0 bg-black/70 z-50" />

{/* Modal container - pointer-events-none prevents backdrop interference */}
<motion.div className="fixed inset-0 z-50 pointer-events-none">
  <GlassCard className="pointer-events-auto">
    {/* Modal content receives clicks */}
  </GlassCard>
</motion.div>
```
