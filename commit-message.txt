## Bug Fixes

### 1. Fixed Mobile Sidebar Not Working
**Problem:** Framer Motion's `animate={{ x: 0 }}` was overriding CSS transforms, 
preventing the sidebar from sliding off-screen on mobile.

**Solution:**
- Added `isMobile` state to track viewport size
- Different animation logic for mobile vs desktop:
  ```typescript
  animate={{ 
    width: isMobile ? 280 : (isExpanded ? 280 : 80),
    x: isMobile ? (isExpanded ? 0 : -300) : 0,
  }}
  ```
- Mobile: Always 280px wide, slides in/out with x animation
- Desktop: Toggles width 280/80px, no x movement
- Added close button (X) inside mobile sidebar header
- Hamburger button hidden when sidebar is open
- Mobile overlay with backdrop blur for closing

### 2. Fixed Navigation Active State
**Problem:** "Marketplace" nav item stayed highlighted when on child routes 
like `/marketplace/portfolio` because `startsWith('/marketplace/')` matched both.

**Solution:**
```typescript
// Check if a more specific child route matches
const hasMoreSpecificMatch = navItems.some(
  other => other.href !== item.href && 
           other.href.startsWith(`${item.href}/`) && 
           (pathname === other.href || pathname.startsWith(`${other.href}/`))
)

const isActive = isExactMatch || (isChildMatch && !hasMoreSpecificMatch)
```
- Parent routes no longer highlight when a child route is active
- Only the most specific matching route is highlighted

### 3. Fixed Icons Not Centered in Collapsed Sidebar
**Problem:** Icons were left-aligned with `px-3` padding in collapsed state.

**Solution:**
```typescript
// Nav items
isExpanded ? 'gap-3 px-3 text-left' : 'justify-center px-2'

// Notifications button
isExpanded ? 'gap-3 px-3' : 'justify-center px-2'

// User profile
isExpanded ? 'gap-3 px-3 justify-between' : 'justify-center px-2'
```
- When collapsed: `justify-center` centers the icon
- When expanded: Normal left-aligned layout with gap

## Technical Details

### Sell Flow
```
1. User clicks "Sell" on holding
2. openSellModal(holding) sets state
3. User sets quantity and price
4. Platform fee calculated (2%)
5. User confirms → executeSell()
6. Transaction created, holdings updated
7. Success screen with tx hash
```

### Retire Flow
```
1. User clicks "Retire" on holding
2. openRetireModal(holding) sets state
3. User sets quantity, beneficiary, reason
4. Impact preview shown (CO₂, cars, trees)
5. User confirms → retireCredits()
6. Certificate generated, holdings reduced
7. Success screen with certificate ID
```

### Impact Calculations
```typescript
const impactCo2 = retireQuantity              // 1 credit = 1 tonne CO₂
const impactCars = retireQuantity / 4.6       // EPA: avg car = 4.6 tonnes/year
const impactTrees = retireQuantity * 16.5     // Trees needed to absorb same CO₂
```
